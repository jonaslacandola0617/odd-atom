## Posting

- **Platforms:** YouTube Shorts and TikTok first, Instagram Reels second. Upload natively to each; don't cross-post with another platform's watermark.
- **Time:** evening to late night in your main audience's time zone; horror does best after dark.
- **Series:** call it *Broadcast 01*, use the same opening tone in every episode, and keep a regular schedule (aim for 3–5 shorts a week while testing).
