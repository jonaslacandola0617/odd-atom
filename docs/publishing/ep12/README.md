## The belief, if commenters ask

- The tiktik is an aswang-type creature in Tagalog and Visayan lore, named after its "tik-tik" sound at night.
- The well-known rule: **loud means far, faint means near**, so a quiet "tik" is the dangerous one.
- Common protections are salt, garlic, a light kept on and, in some places, a buntot pagi (stingray tail); the details vary by region.
- This video is an original story using the belief; it is not a real event.
