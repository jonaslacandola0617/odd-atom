The packaging leads with the same unresolved question as the film, then promises a distinction it actually explains: evidence for a hot early universe versus an unestablished ultimate origin. It does not claim a discovered multiverse, a measured physical singularity, a proved cosmic bounce or a definitive answer to what came before.
