## Facts, if commenters ask

- The Dominicans built it on the hill in the 1910s (most sources: 1913–1915) as a rest house.
- In the Second World War, civilians sheltered there; accounts of the occupation differ.
- It was a hotel from about 1973 to 1987, then abandoned. It is now the Dominican Heritage Hill and Nature Park, a National Historical Site since 2005.
- The ghost stories (knocking, dinner sounds, headless figures) are reported legends. The beheadings in some versions are not documented.
- Search summaries only; re-check before quoting dates.
