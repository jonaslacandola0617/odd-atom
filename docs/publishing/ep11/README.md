## Facts to have ready if commenters ask

- Balete Drive is a real street in New Manila, Quezon City, named after a large balete tree that once stood in the road.
- The White Lady story was already in the newspapers in the 1950s (a later Inquirer column recalls a 1950s press investigation).
- Origin versions conflict: a girl killed on the road, a student, a woman from the Japanese occupation. No real person has been identified.
- It inspired films, including *Hiwaga sa Balete Drive* (1988). We don't use any film's story or images.
- Search summaries only (Inquirer, ABS-CBN, Wikipedia-derived pages); re-check before quoting dates.
