## Facts, if commenters ask

- **The island:** Poveglia, in the Venetian Lagoon between Venice and the Lido.
- **The record:** a quarantine station (lazaretto) for ships from 1793, most sources say until 1814; the buildings were converted in 1922 to a hospital/care home for the elderly, closed in 1968 (one source says 1969).
- **The legend:** the 160,000 dead, the ash soil and the asylum doctor have no source historians accept.
- **Today:** abandoned and closed to visitors.
- Search summaries only; re-check before quoting.
