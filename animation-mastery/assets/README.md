# Reusable original assets

Character textures/expressions and the terrace plate reuse the user's previously approved original artwork. Source-reference pixels are confined to research evidence and are not production assets. This research session did not use image generation or redraw the approved characters.

See [character catalog](characters/catalog.json), [rig contract](rigs/catalog.json), [expression catalog](expressions/catalog.json), [TerraceLayers](environments/TerraceLayers.tsx) and [GardenPlant](props/GardenPlant.tsx). Root/rock/water objects currently live in `src/MasteryStudies.tsx`; they are reusable exported scene content, not yet split into a comprehensive prop library. A generated-looking static plate must be prepared with independent masks/hidden artwork before promising independent animation of every object.
