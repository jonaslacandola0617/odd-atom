# Motion that explains a story

Evidence: [C01, A01–A06, R01, L01, P01, E01](EVIDENCE_INDEX.md). These are interpretations grounded in visible events and coarse unverified transcript context; no audience comprehension experiment has been run.

## Several observed structures

**A state changes and consequences spread.** C01 connects diminishing core, lowering hand, facial response and falling light prominence. The scene communicates depletion/disappointment without narration; narration is still needed to specify the argument about creativity. One state change affects multiple visible systems, instead of several unrelated idle loops.

**Establish intention, violate it, hold the result.** A01 gives the room/request time to read. A02 removes useful belongings while preserving the shell/person. The visual joke exposes a mismatch between a literal goal and an intended result. The empty result matters as much as the removal. If every object were moving continuously before the instruction, the failure would be harder to see.

**Contrast routes, then reveal an incentive.** In A04 the green boat leaves the path taken by the purple racers, turns near rewards/wall and continues with damage. The broader206–220s scout returns to a scoreboard with the burning boat winning. That juxtaposition explains why high reward need not mean successful racing. The two-second native case does not itself contain the whole loop or final score; the guide must not pretend it does.

**Material interaction explains a mechanism.** R01 uses root width/rock separation and warm particles near contact, in a broader sequence about cracks, swelling/hydraulic force and minerals. A generic root wriggle would not communicate that mechanism. Our original B uses a different mechanism—contact, pause, detour, water arrival—and explicitly labels that difference in research documentation.

**Preserve an anchor while revealing scale.** A06 starts with a small readable group, then expands population while a contrasting minority remains visible. This is a visual comparison, not a chart whose exact count we have verified. P01 similarly builds quantity through repeated entrances and accumulation. The source uses many distinct prop shapes and staggered orientations; a single object copied along one synchronized path would be weaker.

**Hold the relevant layer.** L01 keeps an already-exploded section readable while a ray/droplets identify its function. H01's column hold is a counterexample to the idea that every background must always move. Motion attracts attention, so absence of motion can protect a difficult explanation.

## Storyboard contract for future scenes

Before implementation, state what the viewer should infer without narration. Specify what additional fact the voice supplies. Name the visible cause, the necessary contact/constraint, the changed state and a readable aftermath. Decide which information must be established first and which can enter later. Assign environmental motion a job: establish wind, reveal depth, show force, alter illumination or preserve a transition carrier. Remove loops that compete without clarifying place, cause or mood.

The spoken sentence is not automatically one shot. Source proposals often span many ideas; a continuous visual transformation can bridge several statements, while a short comparison can need two compositions. Do not turn each narration chunk into an isolated background slide. Use [storyboarding system](STORYBOARDING_SYSTEM.md) to coordinate the narrative, visual event and handoff before choosing animation curves.
