MEDICINE SCENE — EDITABLE SVG

Open medicine-scene-editable.svg in Inkscape or another SVG editor.
The file contains real Bezier paths, native eye ellipses, gradients and vector
clip paths. It contains no embedded or linked raster images, external fonts,
JavaScript or HTML. The PNG previews are separate files.

This is an image-derived vector reconstruction of the approved medicine PNG,
not a manually drawn-from-scratch illustration. Its shading uses many traced
color regions. Some shading and contours differ from the original image.

The Layers/Objects panel contains named groups for the clinician, head, eyes,
coat, scrubs, trousers, hands, cells, microbes, microscope, foliage and labware.
Use the Node tool to edit curves and Fill & Stroke to edit colors. The silhouette
clips are editable vector paths. Releasing a clip can reveal extra bounded
underpainting geometry within that object. Keep a backup before releasing clips.

Hidden surfaces and painted cast shadows are approximate. This is a static
editable artwork reconstruction, not a finished animation rig or full turnaround.
Moving objects may expose areas requiring manual vector cleanup.

The repository includes comparison/editing demonstrations and a Remotion still
composition that renders this SVG directly. Original approved artwork is unchanged.
